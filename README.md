## Getting Started

**Prerequisites**

- [Python 3.8 or higher](https://www.python.org/downloads/)
- [Git](https://git-scm.com/downloads) (optional, for cloning)

```bash
# Clone the repository
git clone https://github.com/likhitha-113/python-learning.git

# Move into the folder
cd python-learning

# Run any day's program
python day1_basics.py
```

---

## Learning Approach

1. **Consistency**: code every day, even if only for a short session
2. **Active practice**: type every program myself instead of copying
3. **Documentation**: add comments and short notes to each file
4. **Version control**: commit daily with clear messages, such as `Add day 5: loops`
5. **Reflection**: revisit earlier days to reinforce learning
