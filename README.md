## 👩‍💻 About This Challenge

Hi, I'm **Likhitha**, a B.Tech CSE (AI) student from Nellore, India. 👋

I started this repository to learn **Python** the best way I know: by writing code **every single day for 100 days**. Each day I learn one new concept, practice it, and push it to GitHub.

### 🎯 My Goals
- 💪 Build a strong programming foundation
- 🧠 Prepare for **Data Structures & Algorithms** and placements
- 🤖 Get ready for **Machine Learning & Generative AI**
- 🚀 Build real projects to show on my portfolio

### 📌 My Rules
1. Code **at least 1 hour** every day
2. **Commit** the day's work before sleeping
3. **Type the code myself**, no copy-paste
4. Write short **notes** on what I learned
5. If I miss a day, I continue the next day. No guilt, just keep going!

## ▶️ How to Run My Code

```bash

# 2. Go into the repository folder
cd python-learning

# 3. Run any day's program
python day1_basics.py
```
